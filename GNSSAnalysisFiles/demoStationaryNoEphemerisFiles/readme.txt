demoStationaryNoEphemerisFiles/ is to demo and test reading epehemeris from ftp sites.
If successful, the app will download three .rnx files and one .22n file
Once you have run this demo, you should delete or move the .rnx and .22n files 
to a different directory, so that the next time you run it, the app doesn't have a local 
copy to read from, and it will again go to the ftp sites.
