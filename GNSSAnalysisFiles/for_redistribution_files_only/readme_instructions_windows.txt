Windows Installation:
Copy contents of zip file to Desktop.

Run Desktop\GnssAnalysisFiles\for_redistribution\MyAppInstaller_web.exe 
When prompted use the default directories:
1) for the GNSS Analysis App: \Program Files\Android\GnssAnalysis\
2) for MATLAB runtime: \Program Files\MATLAB\

This is important because:
1) The GNSS Analysis App will expect to find this directory when executing 
2) When you first install MATLAB runtime it will take several minutes. When you reinstall
a later version of GNSS Analysis the installation will recognize that you have already 
installed MATLAB runtime, and not waste your time reinstalling it.


Running the app:
Go to \Program Files\Android\GnssAnalysis\application\ and double-click GnssAnalysisApp.exe, 
or double click the shortcut on your desktop. 

BE PATIENT! The first time you run the program it can take a minute or more. 
Hint: open Task Manager, and you can see that something is happening.
